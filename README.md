# Data Analysis & Visualization in R 📊

## 📌 Overview
This repository houses a collection of data analysis scripts focused on dataset cleaning, matrix transformations, logical data filtering, and data visualization. These scripts highlight core data quality competencies: isolating anomalies, standardizing data frames, and extracting analytical insights.

## 🚀 Repository Files & Features

### 1. Data Frame Manipulation & Statistical Filtering (`Data Frames R assignment 4.R`)
* **Concept:** Imported raw text data into structured data frames, applied logical constraints to filter rows based on multiple conditions, and exported cleaned datasets to CSV format.
* **Relevance:** Demonstrates the ability to ingest raw data, standardize it, and run statistical aggregations (`mean`, `median`, `sd`) to validate dataset distributions.

### 2. Data Visualization & Outlier Identification (`Assignment5_Murders.R`)
* **Concept:** Utilized `dplyr` and `ggplot2` to map regional datasets to visual models, utilizing logarithmic scaling and customized aesthetic mapping.
* **Relevance:** Proves proficiency with data visualization concepts (analogous to Looker or PowerBI) to make complex data easily digestible for non-technical audiences and visually identify data outliers.

### 3. Matrix Transformations (`R assignment 3 Matrices.R`)
* **Concept:** Built and transformed matrices, calculated row/column cumulative sums, and performed matrix multiplication to standardize raw data inputs.
* **Relevance:** Showcases an understanding of complex data structures and dimensional analysis, which is critical when reconciling large, multi-variable datasets.

### 4. Data Cleaning & Logical Validation (`R assignment 2.R` & `R assignment 1.R`)
* **Concept:** Developed scripts to handle missing data (`na.omit`), generate random sample distributions, and apply logical indexing to find specific data conditions.
* **Relevance:** Highlights core data quality workflows, specifically using conditional statements (`ifelse`) and logical checks (`all()`, `any()`) to identify anomalies and ensure data integrity.
